# Artificial Intelligence & Machine Learning Projects

## Overview

This repository contains a collection of academic projects focused on Artificial Intelligence, Machine Learning, Deep Learning, and Predictive Analytics, developed as part of my Master's Degree in Data Intelligence at Universidad La Salle.

The projects explore different approaches to data processing, statistical modeling, predictive algorithms, neural networks, and intelligent systems using Python and related analytical libraries.

## Projects

### 1. Predictive Modeling – MLP Regression
**Technologies:** Python, Pandas, NumPy, Scikit-learn, Neural Networks

- Processed historical COVID-19 datasets for predictive analysis.
- Performed feature engineering using moving averages and lagged variables.
- Developed a Multi-Layer Perceptron (MLP) regression model to forecast case counts.
- Explored time-series forecasting and model performance.

### 2. Image Classification – CNN & Transfer Learning
**Technologies:** Python, TensorFlow, Keras, CNN, MobileNetV2

- Developed Convolutional Neural Networks (CNNs) for image classification.
- Implemented transfer learning using the MobileNetV2 architecture.
- Applied image preprocessing, data augmentation, and dropout techniques.
- Explored model evaluation and deep learning optimization.

### 3. Unsupervised Learning – Clustering
**Technologies:** Python, NumPy, Pandas

- Implemented a centroid-based clustering algorithm.
- Applied Euclidean distance to measure similarity between observations.
- Developed iterative cluster assignment and centroid recalculation procedures.
- Explored unsupervised learning and pattern identification.

### 4. Natural Language Processing – Sentiment Analysis
**Technologies:** Python, TensorFlow, Neural Networks

- Prepared and processed text data using the IMDB movie review dataset.
- Explored text preprocessing and word embeddings.
- Developed neural network architectures for binary sentiment classification.
- Investigated deep learning approaches to natural language processing.

### 5. Simulation & Data Processing
**Technologies:** Python, Object-Oriented Programming, Matplotlib, CSV

- Developed an object-oriented simulation program.
- Processed and structured simulation outputs.
- Visualized results using Matplotlib.
- Exported structured datasets for further analysis.
